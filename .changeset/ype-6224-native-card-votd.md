BibleCard and Verse of the Day draw scripture with native text, on the same passage path as BibleReader (YPE-6224). Footnotes and verse numbers match the reader. A missing passage, a failed request, and a lost connection use the reader messages. Failed and offline requests can be retried. The `dom` prop is removed from both components. BibleTextView still uses the WebView.
